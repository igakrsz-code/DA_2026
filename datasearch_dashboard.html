05 / STRATEGIC INSIGHTS
Recommendations for DataSearch
🚀
Market Is Booming
Job postings grew 172% from 2017 to 2021, with a major acceleration in 2020–2021 (likely post-COVID digital transformation push). DataSearch should increase recruiter capacity ahead of continued demand.
☁️
Cloud is Non-Negotiable
Cloud skills (AWS + Azure combined) appear in over 49% of all postings. Candidates without any cloud proficiency are increasingly screened out. DataSearch should prioritize cloud-certified candidates.
🐍
Python + SQL = Table Stakes
Python (8K mentions) and SQL (8.4K mentions) are the top languages by far. Any data candidate lacking both should be considered entry-level regardless of title. Use as a baseline screening filter.
💰
Data Scientists Command Premium Pay
Data Scientists average $147K/year — 70% more than Data Analysts ($86K). Engineers ($134K) close the gap. DataSearch can command higher placement fees for data science roles.
🏙️
Concentrate on Key Metros
San Francisco, New York, and Chicago together account for over 22% of all city-specific postings. These markets warrant dedicated recruiters. Austin and Boston are fast-growing secondary markets.
📊
Mid-Senior Level Dominates
54% of postings target Mid-Senior level candidates — the hardest to source. DataSearch should build a strong talent pipeline of 3–7 year professionals, as competition for them is highest.
🏭
Tech Is the Primary Client Base
Internet, Computer Software, and IT Services together represent 57% of all postings. However, Financial Services (1,227 postings) and Healthcare (828) are significant non-tech verticals worth targeting.
🤖
ML & AI Skills Are Rising Fast
Machine learning appears in 2,990 postings and grew significantly in 2020–2021. DataSearch should develop a specialist ML/AI talent practice, as this segment will command the highest fees going forward.
